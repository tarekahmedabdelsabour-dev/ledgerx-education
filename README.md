# LedgerX Education

One module for every stage: nursery, school and university.

- **Admissions:** applications, interview and test, registration fee, accept and enroll.
- **Students and guardians:** one fees customer per guardian, sibling order for the sibling discount, health notes, school bus.
- **Academic structure:** institutions, stages, grade levels, sections, faculties and departments, subjects, course offerings with a weekly schedule.
- **Fees:** fee structures per grade and year, scholarships, sibling discount, installments on the invoice, payments, credit-hour fees for universities.
- **Daily academics:** class attendance with absence alerts to the class teacher, mark sheets, grading scale, report card, course registration.
- **Reports:** Fees Due, Fee Collection, Class Strength, Attendance Summary, Student Report Card; dashboard cards and charts.

See `docs/INSTALL.md`. Requires erpnext and hrms.
